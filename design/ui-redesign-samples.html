交互模型（三个方向共用）

  1. 键盘优先：Ctrl+K 统一入口（文件搜索 + 命令，同一输入框，前缀 > 切命令）；Ctrl+F 当前目录过滤；Ctrl+Shift+F 全局搜索；F5 刷新（走 USN 快路径）；Ctrl+Shift+R 强制全量；Esc 取消扫描/关闭面板。
  2. 方向键即可完成主流程：↑/↓ 选行、→/← 展开/折叠或进出目录、Enter 打开（资源管理器定位）、Space 预览信息、Backspace 上一级；表格列头 Alt+1..6 直接排序。
  3. 过滤语法常驻可见：过滤框右侧常显语法提示与命中数；输入 ? 展开完整语法；非法 token 标红并保留原文，不静默丢弃。
  4. 状态永远可解释：状态栏固定显示 USN 校验点、缓存层级（内存/磁盘/推导）、索引规模、是否管理员；降级时给出原因与"以管理员重启"一步操作。
  5. 洞察随上下文：底部/侧边洞察区跟随选中目录（体积构成、Top 增长、可清理项、重复候选、快照 diff），并用 Ctrl+1..5 切换。
  6. 危险操作有边界：删除/清理只在"清理清单"里批量执行，先给估算与影响面；程序本身始终只读扫描。

色板（深色 / 浅色同构）

用途深色浅色
窗口底 / 面板 / 浮层#17181a #1e1f22#f3f3f3
强调色（唯一）#4c9aff#0a6ed1
占用热力（5 档）低 → 高（蓝绿 → 黄 → 橙 → 红），只表达数据不表达情绪
语义色正常 注意 危险仅用于状态与告警

字阶与间距

元素规格
UI 文本 / 表格12px / 1.45，行高 23px，密度优先
次级说明 / 状态栏11px
数字 / 路径 / 时间Cascadia Mono 11-12px，等宽对齐（tabular-nums）
标题 / 分组10.5-12px，全大写 + 0.6px 字距，不用大字号
圆角 / 边框统一 3px，分隔线 1px；阴影仅用于浮层
间距节奏4 / 6 / 8 / 10 / 14 px；工具栏 36px、状态栏 24px、标题栏 32px

图标与控件

项规则
图标内联 SVG，14-16px，1.6px 描边，单色跟随文本；不用 emoji、不用彩色图标
按钮高 24px，图标 + 文本；仅主操作使用强调色填充
表格斑马纹极淡 + 悬停高亮 + 选中用强调色 18% 底；数字右对齐
占用条6px 高轨道 + 热力填充 + 右侧百分比（等宽）
动效仅 120ms 背景/边框过渡；扫描进度用宽度过渡；不做位移/缩放动画

三个方向的取舍

方向适合代价
A 指挥台长期驻留、双栏对照（树 + 表 + 检查器），最接近 Everything/Opus 习惯横向空间占用最大
B 仪器台单表信息量最大、洞察坞可拖拽；适合"看数据"为主树/检查器需要弹层或切换
C 工作台浅色、多模式（浏览/搜索/快照/重复）切换清晰，最"软件"模式切换有学习成本
